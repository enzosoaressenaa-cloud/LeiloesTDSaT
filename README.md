\# LeiloesTDSaT



\## Nome do projeto



LeiloesTDSaT



\## Sobre o projeto



O LeiloesTDSaT é um sistema desenvolvido em Java para auxiliar nas rotinas de uma casa de leilões. O sistema tem como objetivo organizar e gerenciar informações relacionadas aos produtos e aos processos de leilão.



\## Tecnologias utilizadas



\- Java

\- MySQL

\- Git

\- GitHub
